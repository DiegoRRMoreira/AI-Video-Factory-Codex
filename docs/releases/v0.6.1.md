# v0.6.1 release notes — draft

Status: preparation only. The root version remains 0.6.0. No v0.6.1 tag or GitHub
release has been created by this preparation.

## Studio library and navigation

- Search episode titles/topics and combine status, series, style and work-queue
  filters, stable sorting and pagination in shareable links.
- Show media spend, agent usage, total cost and budget caps for the matching
  episodes across every page. Cached calls and unrelated episodes are excluded;
  billed failures remain included.
- Follow a clearer next action with affected unfinished stages and estimated
  cost/time up to the next approval gate. Keep all stage details expandable.
- Apply recent-series settings without starting production. Keep advanced options
  and every existing style available under collapsible creation controls.

## Playback and review

- Review findings, selected shots and narration alongside the existing preview
  player or the recorded main/Short output in the Shots workspace.
- Preserve selection, filters and playback positions across episode tabs. Pause
  hidden players and retain preview position through close/reopen cycles.
- Seek main and Short findings in their own output time, reject stale export
  requests and keep code preview distinct from encoded-output evidence.
- Open voice/research findings at their script scene. Prepare a correction without
  automatically starting the existing priced regeneration action.
- Improve keyboard tab navigation and modal focus handling; bound and abort stale
  playback/decision requests so obsolete responses cannot replace newer context.

## Reliability and security

- Add rebuildable episode summaries, lightweight status/revision polling and
  selected-panel payloads. Preserve existing state files and legacy full reads.
- Cache stable JSONL cost snapshots and bind revisions to their own entries.
  Handle concurrent summary publication, repair, restart and module/HMR boundaries.
- Show a localized retry after an initial load failure and disclose stale retained
  data after a refresh failure.
- Limit normal test discovery to owned test locations without weakening coverage.
- Upgrade Studio's Next.js dependency from 16.4.3 to 16.4.5 and update its matching
  env/SWC packages. Registry audit results and scope are recorded in the
  [dependency report](../../security-report/dependency-audit.md).

## Update notes and boundaries

Rebuild and restart Studio after updating to activate the new server/storage/cache
implementations. Existing long-lived objects retain an authoritative-read fallback
until restart. No destructive episode migration or rendering-engine migration is
required. Manual output/file checks and publishing approval remain separate from
recorded work-queue labels and technical audit completion.

Browser visual/mobile and manual accessibility acceptance, human task-time
comparison and live GPU resource profiling must be disclosed separately from
component, API, build and media-fixture results. Publication must identify the exact
tested commit and current hosted CI results; this draft alone is not release proof.
