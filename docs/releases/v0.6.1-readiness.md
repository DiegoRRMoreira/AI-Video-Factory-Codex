## Source and publication boundary

Local evidence is retained under `.temp_files/release-0.6.1-prep-2026-11-17/`, with
source/dependency fingerprints, gate logs, media hashes and the candidate commit.
The preparation commit's hosted [CI workflow](../../.github/workflows/ci.yml) must
be checked at its exact SHA; the final handoff/receipt records that result. A local
green gate does not substitute for hosted CI or validate a later version commit.

The shared checkout retains unrelated settings deletion and tsconfig bytes.
The release helper's clean-tree guard remains enabled. Use a clean checkout of the
verified source for the future `pnpm release patch --dry-run` / publication flow;
preserve unrelated changes in the existing checkout. The release commit/tag and
its exact-SHA CI require their own final checks when publication is requested.
